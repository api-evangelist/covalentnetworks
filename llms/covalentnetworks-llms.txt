# Covalent (Covalent Networks)

> Covalent is a workforce operations platform for industrial manufacturing teams in aerospace & defense and automotive. It digitizes on-the-job training, skills/capability management, workforce scheduling and task execution, and exposes a GraphQL API to integrate workforce, skills and production data with enterprise systems (Workday, SAP, Oracle, UKG, Microsoft, LMS/ERP/MES). Authentication is via AWS Cognito. Backed by Felicis.

## API
- Style: GraphQL (single-request fetch, bidirectional enterprise data flow)
- Auth: AWS Cognito (OAuth2 / OIDC, MFA)
- Integrations: Workday, SAP, Oracle, UKG, Microsoft, HCM/HR, LMS, ERP, MES, Data Warehouses, Active Directory/SSO
- Access: provisioned per tenant via Request a Demo (no public developer portal or OpenAPI)
